# Развёртывание статического сайта КРЯК

## Публичная версия

Сайт публикуется через GitHub Pages как набор статических файлов. Регистрация, авторизация, формы отправки, загрузка файлов, API записи, база данных и cookie приложения отсутствуют. Подключения к Табрике или другому облачному хранилищу нет.

КРЯКтика временно снята с сайта по семейному условию и не может быть возвращена раньше **1 июля 2027 года**. Её исходники остаются в репозитории. Подробности зафиксированы в `КРЯКТИКА-НЕ-ПУБЛИКОВАТЬ-ДО-2027-07-01.md`.

## Сборка GitHub Pages

Workflow `.github/workflows/deploy-pages.yml` создаёт отдельный каталог `_site` и исключает из публикуемого артефакта:

- `портал.html`;
- весь каталог `портал/`;
- `портал-дизайн-система.html`;
- `пользовательское-соглашение-портала.html`;
- внутреннюю памятку о сроке публикации.

Из артефакта также исключаются служебные файлы репозитория: исходные документы из `documents/`, скрипты, локальный сервер, README, инструкция развёртывания и пример окружения.

Сборка завершается ошибкой, если в публичных HTML-файлах остаётся ссылка или упоминание КРЯКтики. Наступление 1 июля 2027 года ничего не публикует автоматически: для возврата потребуется отдельное изменение workflow и навигации.

При таком размещении МХ «КРЯК» не получает через сайт формы, аккаунты, обращения или журналы посетителей. GitHub может самостоятельно обрабатывать технические сведения запросов в соответствии со своими условиями; приложение КРЯК не получает к ним доступа.

## Локальный просмотр

Требуется Python 3.11 или новее. Сторонние пакеты и база данных не нужны.

```bash
python3 server.py
```

Сайт будет доступен по адресу <http://localhost:8000>. Локальный сервер также не выдаёт временно отключённые файлы КРЯКтики.

Локальный сервер:

- обслуживает только публичные статические файлы;
- не создаёт cookie;
- не сохраняет IP-адреса и пути запросов в журнал приложения;
- возвращает HTTP 410 для любого `/api/*`;
- отклоняет POST, PUT, PATCH и DELETE с HTTP 405;
- не обслуживает `.git`, `.env`, каталоги `data` и `documents`;
- возвращает HTTP 404 для файлов и маршрутов КРЯКтики.

## Обязательные ограничения

1. До 1 июля 2027 года не возвращать КРЯКтику на сайт; при более раннем запросе напомнить владельцу об условии мамы.
2. Не добавлять формы, которые отправляют сведения на сервер или стороннюю площадку.
3. Не подключать аналитику, рекламные пиксели, системы обратной связи и внешние формы без отдельной предварительной оценки.
4. Не публиковать email для приёма заявлений, документов или иных сведений о людях.
5. Не добавлять регистрацию, авторизацию, cookie сессий, API или базу данных в текущую статическую архитектуру.
6. Если обработка персональных данных когда-либо понадобится, разрабатывать её как отдельный проект и выполнять правовые и организационные требования до запуска, а не после него.

Это техническая памятка, а не юридическое заключение.

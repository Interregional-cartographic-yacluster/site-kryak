# Статический режим без получения персональных данных от посетителей

Решением владельца сайта КРЯКтика сохранена только как интерактивный демонстрационный макет.

В опубликованной версии отсутствуют:

- регистрация и авторизация;
- личные кабинеты реальных пользователей;
- формы отправки обращений и загрузки файлов;
- API записи и чтения пользовательских данных;
- база пользователей, сессий и обращений;
- cookie приложения;
- подключение Табрики и иных обработчиков;
- аналитика и рекламные трекеры.

`server.py` обслуживает только статические файлы, не ведёт журнал запросов приложения, отклоняет методы записи и возвращает HTTP 410 для любого `/api/*`. Включить обработку переменной окружения невозможно: соответствующий код удалён.

Ранее подготовленные проекты документов, интеграции и уведомления Роскомнадзора удалены из актуальной версии репозитория как не соответствующие принятой архитектуре. Если в будущем будет принято решение собирать персональные данные, функции нельзя просто «включить»: потребуется отдельный проект, предварительная правовая оценка, новые утверждённые документы и выполнение требований до начала обработки.

Это техническое описание архитектуры, а не юридическое заключение.

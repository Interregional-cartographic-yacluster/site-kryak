# Сайт молодёжного движения «КРЯК»

Статический сайт движения «Картографический региональный Я-кластер».

## Локальный просмотр

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

После этого сайт будет доступен по адресу <http://localhost:8000>.

## Публикация

Репозиторий подготовлен к автоматической публикации через GitHub Pages. В настройках репозитория выберите **Settings → Pages → Source → GitHub Actions**. После отправки изменений в ветку `main` workflow опубликует сайт автоматически.

## Локальные изображения

Изображения сайта хранятся в каталоге `assets/images`, чтобы страницы не зависели от сторонних фотохостингов и других репозиториев. Соответствие прежних URL локальным файлам зафиксировано в `assets/images/manifest.json`.

## Файлы электронного архива

Крупные документы электронного архива хранятся в GitHub Release `archive-files-v1`, поскольку общий объём превышает 1 ГБ, а отдельные PDF превышают лимит Git-репозитория в 100 МБ. Исходные адреса Cloud Mail.ru и имена Release assets перечислены в `assets/documents/mailru-manifest.json`. Workflow `mirror-mailru-release.yml` скачивает опубликованные файлы и загружает их в Release; страница `/наш-архив` ссылается непосредственно на Release assets. Перенесены все 51 архивных файла. Для документа `007`, чья исходная ссылка возвращала HTTP 404, используется предоставленная пользователем локальная копия `assets/documents/archive-007.pdf`.
